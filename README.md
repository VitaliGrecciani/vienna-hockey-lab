# Vienna Hockey Lab

Futuristic React/Vite landing page for **Vienna Hockey Lab**. Designed for elite athletes, this high-performance website features interactive fractal physics, modern 3D glassmorphism UI elements, and fluid Framer Motion animations. 

It is built with full GDPR compliance for Austrian law and integrates seamlessly with fully automated backend workflows.

[**Live Demo (Vercel)**](https://vienna-hockey-lab.vercel.app/)

## ✨ Key Features

- **Interactive UI/UX:** Stunning 3D glassmorphism design and fractal physics animations for a premium look and feel.
- **High-Performance:** Built on React and Vite for lightning-fast loading speeds and optimal rendering.
- **Fluid Animations:** Powered by Framer Motion for smooth scroll and interaction effects.
- **GDPR Compliant:** Fully respects privacy and data protection laws applicable in Austria and the EU.
- **Seamless Integrations:** Automated backend pipelines via webhooks (n8n, Telegram notifications, Google Sheets data processing, automated emails via SMTP).
- **Fully Responsive:** Optimized for both mobile and desktop experiences.

## 🛠 Tech Stack

- **Frontend:** React, TypeScript, Vite
- **Styling:** CSS Modules / Styled-components, Framer Motion
- **Automation Pipeline:** n8n, Webhooks, Google Sheets API, Telegram Bot API, SMTP2GO
- **Deployment:** Vercel

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

- Node.js (version 16 or newer)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/VitaliGrecciani/vienna-hockey-lab.git
   ```

2. Navigate into the project directory:
   ```bash
   cd vienna-hockey-lab
   ```

3. Install NPM dependencies:
   ```bash
   npm install
   ```

4. Create a `.env.local` file in the root directory (if there are any required environment variables for the frontend, e.g., tracking IDs). *(Optional)*

5. Start the development server:
   ```bash
   npm run dev
   ```

6. Open your browser and visit `http://localhost:5173`.

## 📦 Deployment

The project is configured for seamless deployment on **Vercel**. Any pushed change to the `main` branch will trigger an automatic build and deployment.
